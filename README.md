## 🇹🇷 Türkçe Açıklama

Bu depo, C# programlama dilinin temel yapı taşlarını ve ilişkisel veritabanı (MSSQL) ile doğrudan **ADO.NET** kullanarak veri yönetimini (CRUD) pekiştirmek için geliştirilmiş pratik ve konsol projelerini içerir.

### 📂 Proje İçerikleri

1. **`01_MainSubjects` (Temel Konular):**
   * C# temel sözdizimi, değişken tipleri, karar yapıları (`if-else`, `switch`), döngüler ve konsol giriş-çıkış operasyonları.
2. **`02_DBProject` (Veritabanı Entegrasyonu):**
   * SQL Server bağlantı dizesi (Connection String) kurulumu, `SqlConnection` yönetimi ve bağlantı testleri.
3. **`03_DBCRUD` (Veri İşlemleri):**
   * `SqlCommand`, `SqlDataReader` ve parametreli SQL sorguları ile temel Ekleme, Okuma, Güncelleme ve Silme (CRUD) pratikleri.
4. **`GamerCRUD` (Oyuncu Yönetim Konsolu):**
   * Oyuncu verilerini SQL Server veritabanında saklayan, listeleyen, güncelleyen ve silen ham ADO.NET konsol uygulaması.

## 🇬🇧 English Description

This repository contains fundamental C# programming exercises and relational database management (CRUD) implementations using native **ADO.NET** and Microsoft SQL Server.

### 📂 Project Overview

1. **`01_MainSubjects` (Language Fundamentals):**
   * Core syntax, data types, control flow, loops, and basic algorithmic concepts.
2. **`02_DBProject` (Database Connectivity):**
   * Connection management, `SqlConnection` lifecycle, and SQL Server connectivity setup.
3. **`03_DBCRUD` (CRUD Operations):**
   * Executing parameterized queries via `SqlCommand` and processing results with `SqlDataReader`.
4. **`GamerCRUD` (Player Management Console):**
   * End-to-end player CRUD console application built with native ADO.NET and relational SQL tables.
